# Documentation map

## Active direction

The active project direction is defined by:

- the root `README.md`;
- the root `AGENTS.md`.

The current goal is exploratory deterministic-AI project-management R&D, beginning with a small working scheduling experiment and progressing through capability/learning gates.

## Parallel STO experiment

`dezrobbo1/STO-Scheduler-Tracker-Research` is a separate, STO-focused scheduling and live-execution research project.

It is not subordinate to PM-Software and should not be frozen merely to avoid duplication. If its current direction is producing useful working capability or evidence, it should continue.

The repositories should exchange useful ideas, tests and code deliberately. A future merge or shared package should happen only if working experiments make that clearly beneficial.

## Historical research

The numbered documents in this directory, the `PHASE-*` snapshots under `docs/archive/`, the schemas, registers and `native-validation/` tree record the earlier formal research programme. They remain useful background and may contain reusable ideas or test cases.

They are not current development gates. New proof-of-concept work does not need to update their protocols, registers, hashes, manifests or native compatibility material unless that work is explicitly restarted.

## Paused areas in PM-Software

The following are paused here while the deterministic-AI core experiments move forward:

- Microsoft Project and P6 native automation;
- semantic-parity and round-trip claims;
- whole-repository evidence manifests;
- production-grade governance and hardening;
- practitioner, buyer and large-scale benchmark programmes.

This pause applies to PM-Software only. It does not instruct the STO repository to stop useful work in those areas if they directly advance its own experiments.
