# Documentation map

## Active direction

The active project direction is defined by:

- the root `README.md`;
- the root `AGENTS.md`.

The current goal is a small working constraint-scheduling proof of concept.

## Historical research

The numbered documents in this directory, the `PHASE-*` snapshots under `docs/archive/`, the schemas, registers and `native-validation/` tree record the earlier formal research programme. They remain useful background and may contain reusable ideas or test cases.

They are not current development gates. New proof-of-concept work does not need to update their protocols, registers, hashes, manifests or native compatibility material unless that work is explicitly restarted.

## Paused areas

The following are paused while the core proof of concept is built:

- Microsoft Project and P6 native automation;
- semantic-parity and round-trip claims;
- whole-repository evidence manifests;
- production-grade governance and hardening;
- practitioner, buyer and large-scale benchmark programmes.
